## Implemented candidate

- Capability discovery preserves browser protocol 1.0 and advertises the optional persistent extension.
- Pairing captures an exact validated P-256 public key before code display; a default-selected local remember control appears only for capable requests. Unchecking and old owner approval omission remain session-only.
- Separate owner-protected schema-1 authorization storage keeps Connector installation identity, exact origin, stable workbench identity, public key/fingerprint, display hint, created/last-use timestamps and revocation. Inbox schema 2 is unchanged.
- Short in-memory sessions remain host-instance-bound. New verified proof creates a new session; each active session check verifies the durable grant and touches last use. Ninety-day expiry uses the exact boundary, never failed requests, and clocks cannot move last use backwards.
- Domain/purpose/origin/Connector/grant-bound 60-second challenges use SHA-256/P-256 with 64-byte P1363 signatures, are consumed before host awaits and rechecked before issuance. Host-offline proof preserves a grant without extending it; wrong stable host or installation cannot inherit trust.
- Browser proof and local owner revocation invalidate all grant sessions/challenges. Disconnect only ends its session. Revocation cannot retract a previously durable receipt.
- The local Remembered browsers product page lists exact origins, display labels, key fingerprints and creation/last-use/expiry/state; per-record Forget is available for active or expired authorizations. CLI and MCP provide entry points without exposing management tickets in model-visible results.
